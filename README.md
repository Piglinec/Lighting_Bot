# ⚡ Бот графика отключений — Волынская область

Telegram-бот, который каждые N минут проверяет график погодинных отключений (ГПВ) «Волиньобленерго» и пишет:

- **«Опубликован график»** — когда появился график на новый день, с часами отключений для вашей подочереди;
- **«График изменён»** — когда поменялись часы именно вашей подочереди (новые и прежние часы);
- **«Через ~30 мин отключение»** — напоминание перед началом отключения.

К уведомлениям прикладывается картинка графика. Если что-то поменялось только у других подочередей, бот молчит.

## Откуда данные

Сайт energy.volyn.ua закрыт защитой Cloudflare, и программы его не открывают. Но картинку графика сайт берёт из открытого API `api-voe-poweron.inneti.net`, и бот читает её оттуда же: смотрит архив версий и распознаёт таблицу по цветам ячеек. Если «Волиньобленерго» поменяет оформление картинки, бот не будет угадывать: он пришлёт саму картинку с пометкой «не удалось распознать».

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Узнайте свою подочередь по адресу: https://energy.volyn.ua/spozhyvacham/perervy-u-elektropostachanni/cherga/
3. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN` (остальное по желанию).
4. Установите зависимость и запустите:

```bash
pip install -r requirements.txt
python bot.py --dry-run   # проверка: покажет текущий график по всем подочередям
python bot.py             # запуск бота
```

5. Напишите боту `/start` и выберите подочередь кнопкой.

Бот должен работать постоянно: на домашнем компьютере, Raspberry Pi или недорогом VPS. Вместо этого его можно запускать бесплатно на GitHub Actions (см. ниже).

### GitHub Actions (бесплатно, без своего сервера)

В этом режиме GitHub раз в 5 минут запускает `python bot.py --once`: бот отвечает на накопившиеся команды, проверяет график, шлёт уведомления и сохраняет состояние в ветку `state`.

1. Создайте на GitHub **публичный** репозиторий (в публичных репозиториях Actions бесплатны без лимита) и загрузите в него эти файлы вместе с папкой `.github`. Файл `.env` не загружайте.
2. **Settings → Secrets and variables → Actions → Secrets → New repository secret**:
   - `BOT_TOKEN` — токен бота (обязательно);
   - `ADMIN_CHAT_ID` — ваш chat_id (необязательно);
   - `ALLOWED_CHAT_IDS` — если бот только для себя (необязательно).
3. Там же на вкладке **Variables** можно задать `DEFAULT_QUEUE` (например `3.1`), `REMIND_BEFORE_MIN`, `SEND_IMAGE`.
4. **Settings → Actions → General → Workflow permissions** → выберите *Read and write permissions*.
5. **Actions → Проверка графика → Run workflow** — первый ручной запуск. Потом всё пойдёт по расписанию.

Особенности этого режима:
- на команды бот отвечает не сразу, а при следующем запуске (обычно через 5–10 минут);
- GitHub может задерживать запуски по расписанию, особенно в начале часа, а при высокой нагрузке иногда их пропускает;
- в публичном репозитории ветка `state` видна всем: в ней chat_id подписчиков и их подочереди. Токен лежит в Secrets и никому не виден.

### Docker

```bash
docker build -t volyn-light-bot .
docker run -d --name volyn-light-bot --restart unless-stopped \
  --env-file .env -v volyn-bot-data:/data volyn-light-bot
```

### systemd (Linux-сервер)

`/etc/systemd/system/volyn-light-bot.service`:

```ini
[Unit]
Description=Volyn light schedule bot
After=network-online.target

[Service]
WorkingDirectory=/opt/volyn_light_bot
ExecStart=/usr/bin/python3 /opt/volyn_light_bot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now volyn-light-bot
journalctl -u volyn-light-bot -f
```

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Подписаться и выбрать подочередь |
| `/queue` | Сменить подочередь (можно сразу: `/queue 3.1`) |
| `/now` | График на сегодня и завтра |
| `/remind 15` | Напоминать за 15 мин до отключения, `/remind 0` — выключить |
| `/stop` | Отписаться |

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от BotFather |
| `CHECK_INTERVAL_MIN` | `5` | Как часто проверять график, минут |
| `REMIND_BEFORE_MIN` | `30` | Напоминание до отключения, минут (`0` — выключено) |
| `SEND_IMAGE` | `1` | Прикладывать картинку графика |
| `ADMIN_CHAT_ID` | — | Ваш chat_id: сюда придёт сообщение, если источник недоступен больше часа |
| `DEFAULT_QUEUE` | — | Подочередь для `ADMIN_CHAT_ID` сразу при запуске |
| `ALLOWED_CHAT_IDS` | — | Список chat_id через запятую, чтобы сделать бота личным |
| `STATE_FILE` | `state.json` | Где хранить подписчиков и последние графики |

## Важно

Бот показывает **опубликованный график**, а не фактическое наличие света. По предупреждению самого «Волиньобленерго», из-за переключения очередей свет могут выключить на 20–30 минут раньше или позже. Аварийные отключения (ГАВ) в этот график не попадают.
