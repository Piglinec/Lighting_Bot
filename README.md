# ⚡ Бот графіка відключень — Волинська область

Telegram-бот, який кожні кілька хвилин перевіряє графік погодинних відключень (ГПВ) «Волиньобленерго» і пише:

- **«Опубліковано графік»** — коли з'явився графік на новий день, з годинами відключень для вашої підчерги;
- **«Графік змінено»** — коли змінилися години саме вашої підчерги (нові й попередні);
- **«Приблизно через 30 хв відключення світла»** — нагадування перед початком відключення.

До сповіщень додається картинка графіка. Якщо змінилося щось лише в інших підчергах, бот мовчить.

## Звідки дані

Сайт energy.volyn.ua захищений Cloudflare, і програми його не відкривають. Але картинку графіка сайт бере з відкритого API `api-voe-poweron.inneti.net`, і бот читає її звідти ж: переглядає архів версій і розпізнає таблицю за кольорами клітинок. Якщо «Волиньобленерго» змінить оформлення картинки, бот не вгадуватиме: він надішле саму картинку з позначкою «не вдалося розпізнати».

## Команди бота

| Команда | Що робить |
|---|---|
| `/start` | Підписатися й обрати підчергу |
| `/queue` | Змінити підчергу (можна одразу: `/queue 3.1`) |
| `/now` | Графік на сьогодні й завтра |
| `/remind 15` | Нагадувати за 15 хв до відключення, `/remind 0` — вимкнути |
| `/stop` | Відписатися |

Свою підчергу можна дізнатися за адресою: https://energy.volyn.ua/spozhyvacham/perervy-u-elektropostachanni/cherga/

## Запуск на GitHub Actions (безкоштовно, без власного сервера)

У цьому режимі GitHub кожні 5 хвилин запускає `python bot.py --once`: бот відповідає на команди, що накопичилися, перевіряє графік, надсилає сповіщення і зберігає стан у гілку `state`.

1. Створіть бота в [@BotFather](https://t.me/BotFather) (`/newbot`) і скопіюйте токен.
2. Створіть на GitHub **публічний** репозиторій (у публічних репозиторіях Actions безкоштовні без ліміту) і завантажте в нього ці файли разом із папкою `.github`. Файл `.env` не завантажуйте.
3. **Settings → Secrets and variables → Actions → Secrets → New repository secret**:
   - `BOT_TOKEN` — токен бота (обов'язково);
   - `ADMIN_CHAT_ID` — ваш chat_id (необов'язково);
   - `ALLOWED_CHAT_IDS` — якщо бот лише для себе (необов'язково).
4. Там само на вкладці **Variables** можна задати `DEFAULT_QUEUE` (наприклад `3.1`), `REMIND_BEFORE_MIN`, `SEND_IMAGE`.
5. **Settings → Actions → General → Workflow permissions** → оберіть *Read and write permissions*.
6. **Actions → Перевірка графіка → Run workflow** — перший ручний запуск. Далі все піде за розкладом.

Особливості цього режиму:
- на команди бот відповідає не одразу, а під час наступного запуску (зазвичай за 5–10 хвилин);
- GitHub може затримувати запуски за розкладом, особливо на початку години, а під час високого навантаження інколи їх пропускає;
- частоту перевірки задає рядок `cron` у `.github/workflows/check.yml` (мінімум — раз на 5 хвилин);
- у публічному репозиторії гілку `state` бачать усі: у ній chat_id підписників та їхні підчерги. Токен зберігається в Secrets і його ніхто не бачить.

## Постійний запуск (миттєві відповіді)

На домашньому комп'ютері, Raspberry Pi або недорогому VPS:

```bash
cp .env.example .env      # впишіть BOT_TOKEN
pip install -r requirements.txt
python bot.py --dry-run   # перевірка: покаже поточний графік для всіх підчерг
python bot.py             # запуск бота
```

### Docker

```bash
docker build -t volyn-light-bot .
docker run -d --name volyn-light-bot --restart unless-stopped \
  --env-file .env -v volyn-bot-data:/data volyn-light-bot
```

### systemd (Linux-сервер)

`/etc/systemd/system/volyn-light-bot.service`:

```ini
[Unit]
Description=Volyn light schedule bot
After=network-online.target

[Service]
WorkingDirectory=/opt/volyn_light_bot
ExecStart=/usr/bin/python3 /opt/volyn_light_bot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now volyn-light-bot
journalctl -u volyn-light-bot -f
```

## Налаштування

| Змінна | За замовчуванням | Опис |
|---|---|---|
| `BOT_TOKEN` | — | Токен від BotFather |
| `CHECK_INTERVAL_MIN` | `5` | Як часто перевіряти графік у постійному режимі, хвилин |
| `REMIND_BEFORE_MIN` | `30` | Нагадування до відключення, хвилин (`0` — вимкнено) |
| `SEND_IMAGE` | `1` | Додавати картинку графіка |
| `ADMIN_CHAT_ID` | — | Ваш chat_id: сюди прийде повідомлення, якщо джерело недоступне понад годину |
| `DEFAULT_QUEUE` | — | Підчерга для `ADMIN_CHAT_ID` одразу під час запуску |
| `ALLOWED_CHAT_IDS` | — | Список chat_id через кому, щоб зробити бота особистим |
| `STATE_FILE` | `state.json` | Де зберігати підписників і останні графіки |

## Важливо

Бот показує **опублікований графік**, а не фактичну наявність світла. За попередженням самого «Волиньобленерго», через перемикання черг світло можуть вимкнути на 20–30 хвилин раніше або пізніше. Аварійні відключення (ГАВ) у цей графік не потрапляють.
